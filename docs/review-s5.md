## 사용자 피드백 반영

| 항목 | 상태 | 반영 |
|---|---|---|
| 박스 제거 | 반영 | 탭과 개체 보관 화면을 제거했다. 새 탭은 파티 / 도감 / 상점 / 가방 / 설정이다 |
| 빈 칸에서 소환 | 반영 | 목적지 칸을 지정해 등록 도감을 연다. 종을 선택한다. 소환한다 |
| 도감 등록 | 반영 | 전체 목록과 등록을 구분했다. 미등록 종은 소환할 수 없다 |
| 교체와 소환 해제 | 반영 | 기존 종의 등록과 육성 기록을 유지한다. 취소·실패 시 배치를 유지한다 |
| 진화 전 종 재소환 | 설계 반영 | 진화 전후 등록을 모두 유지한다. 별도 보관 개체를 복제하는 설계는 폐기했다 |
| 구매·부화 | 반영 | 포켓몬 구매와 부화 결과를 도감 등록으로 연결한다 |
| 가방 대상 | 제안 반영 | 현재 소환한 포켓몬을 대상으로 선택한다. 빈 파티에서는 사용을 비활성화한다 |
| 이전 피드백 | 유지 | 눈 아이콘, 지방 선택, 이로치 명칭, 별명·모습·먹이·에버스톤 제거, 진화의돌, 작업 부화, 설정 내부 연결 |
