# S5 설계 검토 — 도감 소환과 가방

날짜: 2026-09-18. 범위: 설계와 독립 HTML 시안. 기능 구현 미시작.

## 사용자 피드백 반영

| 항목 | 상태 | 반영 |
|---|---|---|
| 박스 제거 | 반영 | 탭과 개체 보관 화면을 제거했다. 새 탭은 파티 / 도감 / 상점 / 가방 / 설정이다 |
| 빈 칸에서 소환 | 반영 | 목적지 칸을 지정해 등록 도감을 연다. 종을 선택한다. 소환한다 |
| 도감 등록 | 반영 | 전체 목록과 등록을 구분했다. 미등록 종은 소환할 수 없다 |
| 교체와 소환 해제 | 반영 | 기존 종의 등록과 육성 기록을 유지한다. 취소·실패 시 배치를 유지한다 |
| 진화 전 종 재소환 | 설계 반영 | 진화 전후 등록을 모두 유지한다. 별도 보관 개체를 복제하는 설계는 폐기했다 |
| 구매·부화 | 반영 | 포켓몬 구매와 부화 결과를 도감 등록으로 연결한다 |
| 가방 대상 | 제안 반영 | 현재 소환한 포켓몬을 대상으로 선택한다. 빈 파티에서는 사용을 비활성화한다 |
| 이전 피드백 | 유지 | 눈 아이콘, 지방 선택, 이로치 명칭, 별명·모습·먹이·에버스톤 제거, 진화의돌, 작업 부화, 설정 내부 연결 |

### Figma 포켓몬 상세 컴포넌트 — 2026-09-18

- 대상: 기존 파티 화면 `34:219`와 Components 페이지 `7:2`.
- 추가 변수: 상태 배경·문자 3개, 기본 색 3개, 선 굵기 2개. 총 변수 47개. WEB 표기 누락 0개. ALL_SCOPES 0개.
- 상태 안내: Warning·Success·Error 3종. 제목과 설명을 TEXT 속성으로 제공한다.
- 프로필: 이미지, 종 이름, 레벨, 성격, 친밀도, 숨김 BOOLEAN을 제공한다. 몬스터볼은 16.032×16px이며 그림자가 없다.
- 돌봄: Ready·Processing·Disabled 3종. 공통 Button 인스턴스를 사용한다.
- 크기: 1~6 예시를 구성했다. 단계 버튼은 Default·Selected·Focus·Disabled를 제공한다.
- 설정 행: Title·Description·Control INSTANCE_SWAP 속성을 제공한다.
- 확인창: Title·Message·Show Error 속성을 제공한다. 소환 해제 뒤 도감 등록과 육성 기록을 유지한다는 문구를 포함한다.
- 캡처 확인: 상태 안내, 프로필, 돌봄, 크기 선택, 설정 행, 확인창에서 텍스트 잘림과 겹침이 없다.
- 수정: 넓은 프로필에서 친밀도 막대 값 비율이 유지되도록 공통 컴포넌트의 내부 제약을 수정했다.
- 제한: 크기 선택의 Figma 화면 이동 연결은 세트 내부 목적지 제약으로 연결하지 않았다. 런타임 동작은 구현하지 않았다.
- 상세 화면 전체 조립, 도감·가방·진화 화면, Code Connect는 미착수다.
