# 아이콘 시안 계획

## 목표

컴퓨터 화면 위에 몬스터볼이 있고, 그 위에서 작은 펫들이 노는 느낌을 128×128 SVG 아이콘으로 표현한다.

## 범위

- `assets/icon-concepts/`에 128×128 SVG 시안 네 개를 만든다.
- 특정 포켓몬의 공식 얼굴이나 도감 그림은 사용하지 않는다.
- 기존 `assets/logo/`는 읽거나 수정하지 않는다.
- 앱의 실제 아이콘 연결과 PNG·ICO 변환은 이번 작업 범위가 아니다.

## SSOT

- 방향: `docs/design.md`
- 진행 상태: `docs/progress.md`
- 시안 파일: `assets/icon-concepts/*.svg`
- 검수: `docs/review-icon-concepts.md`

## 방향

1. `screen-ball.svg`: 모니터를 배경으로 크게 읽히는 몬스터볼.
2. `screen-playground.svg`: 화면 안에서 뛰는 두 펫과 아래의 몬스터볼.
3. `monitor-buddy.svg`: 모니터 프레임을 펫의 놀이터처럼 쓰는 구도.
4. `window-orbit.svg`: 작은 터미널 창과 몬스터볼을 하나의 앱 배지로 묶는 구도.

## 피드백 반영 방향

기존 시안은 모니터 그림처럼 보였다. 그래서 프로그램 아이콘 인상이 약했다. 후속 시안은 둥근 사각형 앱 타일을 기본 실루엣으로 사용한다. 화면 창, 펫, 몬스터볼은 타일 안의 작은 기호로 압축한다.

- `app-window-ball.svg`: 어두운 앱 타일과 흰색 프로그램 창.
- `app-buddy-badge.svg`: 밝은 배경과 앱 배지의 대비.
- `app-desktop-pet.svg`: 창 안의 펫과 커서 모양의 몬스터볼.

## 위험과 통과 조건

- 128px에서 외곽선과 중심 형태가 뭉개질 수 있다.
- 투명 배경에서 실루엣과 화면이 분리되어야 한다.
- SVG에 외부 파일, 글꼴, 스크립트를 사용하지 않는다.
- 모든 파일의 `viewBox`는 `0 0 128 128`이어야 한다.
- 모든 파일의 실제 크기는 `128`×`128`이어야 한다.
