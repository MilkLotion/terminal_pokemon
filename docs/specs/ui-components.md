# UI 컴포넌트 계약

날짜: 2026-09-23. 상태: 계약 초안. 사용자 검토 전. Figma 수정과 기능 구현 미시작.
근거: [07 · 와이어프레임](https://www.figma.com/design/MA3K41Y6omAi5mRu6YDFly/pokebuddy?node-id=252-121)의 WF-01~WF-09와 상태 예시, Figma `00`~`04` 자산의 읽기 전용 확인, [작업 기록](../work/s5-design-system-v2/plan.md#ui-컴포넌트-계약-추출-설계).

## 읽는 기준

이 문서는 화면에서 반복되는 UI의 계약이다. 게임 규칙은 [현재 설계](../design.md)와 [S5 기능 계약](s5.md)을 따른다. 흐름은 [사용자 시나리오](s5-scenarios.md)를 따른다.
각 계약의 동작은 확정 규칙에서 가져왔다. 크기·배치·문구는 와이어프레임의 제안이며 `[스펙 미확정]`이다.
판정은 기존 Figma 자산 기준이다. `재사용`은 그대로 쓴다. `수정`은 기존 자산에 변형이나 속성을 더한다. `신규`는 새로 만든다.

## 계약

### C-01 앱 헤더

역할: 관리 창 맨 위에서 브랜드, 보유 포인트, 업적창·설정 진입을 보여준다.
내용: 브랜드, 보유 포인트, C-02 업적 아이콘, C-02 설정 아이콘.
상태: 업적 미수령 있음·없음. 업적 모달 열림. 설정 모달 열림.
사용 화면: 관리 창 모든 탭, WF-01~WF-05, WF-01b.
판정: `App Header`에 업적·설정 아이콘 자리를 더한다. 기존 설정 탭 진입은 아이콘으로 옮긴다.

### C-02 헤더 아이콘 버튼

역할: 업적창과 설정 모달을 연다.
상태: 기본, 모달 열림(진한 배경). 업적 아이콘은 미수령 보상이 있으면 우측 위에 dot를 표시한다.
규칙: 미수령 dot는 업적 아이콘에만 쓴다. 부화·진화에는 쓰지 않는다.

### C-03 메인 탭

역할: 파티 / 박스 / 도감 / 상점 / 가방 사이를 이동한다.
상태: 탭별 선택(옅은 배경과 밑줄), 기본. 업적·설정 모달이 열려도 탭 선택은 그대로다.
판정: `Primary Navigation`의 `Active` 변형을 `Party|Box|Pokédex|Shop|Bag`로 바꾼다. `Settings`를 뺀다. 박스 아이콘이 새로 필요하다. 선택 밑줄은 사용자 수정 내비게이션 `114:967`의 규칙을 유지한다.

### C-04 파티 칸 카드

역할: 파티 2열×3행의 한 칸을 보여준다.
상태: `포켓몬`, `포켓몬·숨김`, `빈 칸`, `잠긴 칸`. 잠긴 칸은 출처 문구 `상점에서 구매`·`업적 보상으로 열기`를 가진다.
내용(포켓몬): 원형 초상과 숨김 마커, 레벨, 상태 dot, 이름, 타입 배지와 성격, C-05 친밀도·만복도를 한 줄에 나란히.
내용(빈 칸·잠긴 칸): 가운데 아이콘, 제목, 설명 한 줄. 빈 칸 설명은 `박스에서 배치`다.
규칙: 같은 줄 카드 높이를 맞춘다. 와이어프레임 크기는 330×160이다. 빈 칸을 누르면 박스 개체 고르기(C-13)로 이어진다.
판정: `Pokemon Card`와 `Party Slot Card`를 하나의 상태 세트로 묶는다. 만복도를 더한다. 승인 UI의 `빈 슬롯`·`잠긴 파티칸`·`도감에서 소환` 문구를 용어사전 기준으로 바꾼다.

### C-05 수치 막대

역할: 친밀도, 만복도, 경험치를 이름·수치·막대로 보여준다.
변형: 넓게(한 줄에 하나), 좁게(한 줄에 둘). 좁게는 수치를 `85/100`으로 붙여 쓴다.
규칙: 채움 길이는 수치 비율이다. 예상 경험치처럼 현재와 다른 값은 시각 디자인 단계에서 구분 표현을 정한다.
판정: `Friendship`을 이름·수치를 바꿀 수 있는 공통 막대로 수정한다.

### C-06 박스 칸

역할: 30칸 박스의 한 칸을 보여준다.
상태: `개체`, `빈 칸`, `선택`.
내용: 원형 초상, 이름, 레벨. 숨긴 개체 표시는 없다. 박스 개체는 파티 밖이기 때문이다.
변형: 박스 탭용 기본 크기, 개체 선택 창용 작은 크기.
규칙: 빈 칸은 옅은 회색 면이며 누를 수 없다. 개체를 누르면 상세로 이어진다.

### C-07 박스 넘김·검색 줄

역할: 박스를 넘기고 모든 박스에서 개체를 찾는다.
내용: `◀`, `박스 N`, `사용 칸 / 30`, `▶`, 이름 검색, 정렬.
규칙: 검색은 모든 박스를 대상으로 한다. 결과를 누르면 그 박스로 이동한다. 줄 안의 버튼과 입력칸 높이를 맞춘다. 박스가 모두 차면 새 박스가 생긴다.
사용 화면: 박스 탭, 박스 개체 고르기, 가방 사용 패널의 `박스`.
`[스펙 미확정]` 정렬 기준과 박스 이름 변경.

### C-08 알 칸과 돌보미집 띠

역할: 박스 메뉴 안에서 알 6칸의 상태를 한 줄로 보여준다.
알 칸 상태: `준비 중`(남은 시간 `3:12 남음`), `부화 가능`(`열기` 버튼), `빈 칸`(옅은 회색 면).
띠 내용: `돌보미집`, `알 N / 6`, 알 칸 6개.
규칙: 알을 누르면 쓰다듬기·노래 들려주기를 할 수 있다. 준비가 끝나도 `열기`를 눌러야 부화한다. 빈 칸은 누를 수 없다.

### C-09 가방 아이템 카드

역할: 가방의 도구 하나와 보유 수량을 보여준다.
상태: 기본, 선택(왼쪽 막대와 옅은 배경).
내용: 아이콘, 이름, `×수량`.
`[스펙 미확정]` 보유 0개가 된 도구를 목록에서 뺄지 남길지.

### C-10 상점 상품 카드

역할: 상점 상품 하나를 보여주고 구매 창을 연다.
내용: 아이콘, 이름, 한 줄 설명, 가격, `›`. 카드에 `구매` 버튼을 두지 않는다.
규칙: 구매할 수 없어도 카드는 누를 수 있다. 이유와 비활성 `구매`는 구매 창(C-13)에서 보여준다.

### C-11 도감 종 카드

역할: 도감 목록의 한 항목을 보여준다.
상태: `획득`, `해금`, `미해금`(`???`), `선택`. 이로치 획득은 작은 표시를 더한다.
내용: 초상, 번호, 이름, 상태 문구.
규칙: 리전폼은 별도 카드다. 해금과 획득의 초상 구분은 시각 디자인 단계에서 정한다.

### C-12 업적 행

역할: 업적 하나의 조건·보상·수령 상태를 보여준다.
상태: `받기 가능`(진한 `받기` 버튼), `미달성`, `받음`. 미달성과 받음은 같은 회색 면 상태 표시다.
내용: 업적 표시, 이름, 조건, 보상.
규칙: 목록은 미수령 → 미달성 → 수령 완료 순서다. 보상은 `받기`에서만 지급한다.

### C-13 대화상자

역할: 모달의 공통 틀이다.
내용: 머리(제목, 부제, `✕`), 본문, 바닥(보조 버튼, `취소`, 주 버튼).
변형: 폭 440(구매 창), 폭 600(업적창·설정·개체 선택). 본문 스크롤 여부.
사용: 업적창, 설정, 박스 개체 고르기, 파티 칸 고르기, 구매 창, 기존 확인 창.
판정: `Confirm Dialog`를 공통 틀로 수정한다. 배경은 `Modal Scrim`을 재사용한다.
`[스펙 미확정]` Esc와 바깥 클릭으로 닫기.

### C-14 수량 조절

역할: 한 번에 사용하거나 살 수량을 고른다.
내용: `−`, 수량, `+`, 선택적 `최대`, 보유·최대 안내.
사용: 가방 사용 패널, 상점 구매 창.
규칙: 사탕의 최대 수량은 보유량과 100레벨 도달 개수 중 작은 값이다.

### C-15 두 칸 전환

역할: 두 선택지 중 하나를 고른다.
사용: 가방 사용 패널의 `파티 | 박스`, 설정의 `일반 | 연결`, 설정의 `화면 전체 | 영역 지정`.
규칙: 회색 틀 안에서 고른 칸만 흰 면이다.

### C-16 필터 칩

역할: 목록의 분류나 필터를 고른다.
사용: 가방·상점 분류, 도감 필터.
규칙: 고른 칩은 진한 채움과 흰 글자다. 같은 줄 칩의 높이를 맞춘다.

### C-17 대상 목록 행

역할: 사용 대상 한 마리를 고른다.
내용: 작은 초상과 숨김 마커, 이름, 레벨.
상태: 기본, 선택(왼쪽 막대와 옅은 배경).
사용: 가방 사용 패널.

### C-18 설정 행과 토글

역할: 설정 항목 하나와 그 조작을 보여준다.
조작: 토글, 선택, 두 칸 전환(C-15), 버튼.
판정: `Setting Row`의 `Control` 교체 속성을 재사용한다. 토글은 새로 만든다.

### C-19 업적 배너

역할: 바탕화면 우측 아래에 업적 달성을 한 번 알린다.
내용: `업적 달성`, 업적 표시와 이름, `바로가기`.
규칙: 배너에서 보상을 주지 않는다. `바로가기`는 업적창 모달을 연다. 누르지 않으면 사라진다. 배너는 하나씩 순서대로 뜬다.
`[스펙 미확정]` 부화·진화 배너의 구성, 표시 시간, 다중 화면 기준.

### C-20 배고픔 말풍선

역할: 보이는 포켓몬이 배고픔 알림 구간에 들어갈 때 한 번 표시한다.
`[스펙 미확정]` 문구, 위치, 표시 시간.

### C-21 포켓몬 위 우클릭 메뉴

역할: 포켓몬 위에서 우클릭하면 이름·상태 / 밥 주기·놀아주기 / 설정을 보여준다.
규칙: 빈 곳 우클릭은 가로채지 않는다. 종료를 두지 않는다. 상태는 만복도·기분 구간 이름으로 보여준다.
형태: OS 기본 메뉴가 아니라 앱이 직접 그리는 메뉴다. 구분선·상태 문구·여백은 관리 창과 같은 디자인 규칙을 따른다. Windows와 macOS에서 같은 모양이다. 근거는 [앱이 그리는 우클릭 메뉴](../work/s5-design-system-v2/plan.md#앱이-그리는-우클릭-메뉴)를 따른다.
구현 조건: 방향키·Enter·Esc 조작을 제공한다. 메뉴 바깥을 누르면 닫는다. 화면 가장자리에서는 뜨는 방향을 뒤집어 잘리지 않게 한다. 다중 화면과 배율을 맞춘다. 투명한 놀이공간 창은 메뉴 영역과 포켓몬 그림만 클릭을 받고 나머지는 계속 통과시킨다.

### C-22 빈 상태 줄

역할: 목록이 비었거나 검색 결과가 없을 때 한 줄로 알린다.
사용: 빈 박스(`보관 개체 없음`), 도감 검색(`검색 결과 없음`).
