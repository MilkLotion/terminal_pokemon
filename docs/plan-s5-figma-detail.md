# S5 포켓몬 상세 Figma 설계

날짜: 2026-09-18. 갱신: 2026-09-19. 상태: 상세 컴포넌트와 대표 화면 조립·검수 완료. 앱 기능 구현 미시작.

## 목표와 범위

- 기존 파티 화면 `34:219`에서 이어지는 포켓몬 상세 화면을 만든다.
- 색상·글꼴·버튼·헤더·메뉴는 기존 S5 자산을 재사용한다.
- 새로운 상태 안내, 상세 프로필, 돌봄 항목, 설정 행, 크기 선택, 확인창을 컴포넌트로 만든다.
- 반복하는 상세 구역 제목에는 `Detail / Section Header` 컴포넌트를 사용한다.
- 기본 상세, 숨김 상세, 돌봄 결과, 소환 해제 확인·실패 상태를 설계한다.
- Figma 프로토타입은 화면 이동과 상태 예시만 보여 준다. 게임 명령과 저장은 실행하지 않는다.
- 전체 도감·상점·가방·설정 화면과 앱 코드는 이번 범위가 아니다.

## 근거와 충돌 해결

- 결정: [design.md](design.md). 상태: [progress.md](progress.md). 기능 계약: [plan-s5.md](plan-s5.md).
- 시각 기준: [S5 UI 계획](plan-s5-figma-ui.md). 자산 기준: [figma-s5-inventory.json](figma-s5-inventory.json).
- Code Connect 파일은 없다. 런타임 컴포넌트와 대응하지 않으므로 Code Connect는 만들지 않는다.
- Outfit·Inter를 유지한다. 이전 HTML 색상보다 확정 Figma 색상을 우선한다.
- 외부 라이브러리는 로컬 토큰·속성 구조와 다르다. 기존 로컬 자산을 확장한다.
- 숨김은 작은 닫힌 몬스터볼로 표시한다. 이전 눈 아이콘 규칙을 대체한다.

## 화면과 행동

| 영역 | 정보 | 행동 |
|---|---|---|
| 상세 상단 | 파티 위치, 종 이름, 레벨, 성격, 타입, 친밀도 | 파티로 돌아가기 |
| 상태 안내 | 배고픔·피로의 디버프 설명 | 돌봄 영역에서 대응 |
| 돌봄 | 밥 주기, 놀아주기와 짧은 설명 | 처리 중 중복 클릭 방지. 성공·실패 피드백 |
| 표시 설정 | 표시 상태와 크기 | 숨기기·다시 표시. 크기 1~6 예시 선택 |
| 성장과 도구 | 진화 조건·가방 진입 | 선택한 포켓몬을 다음 화면의 대상으로 유지 |
| 파티 관리 | 교체·소환 해제 | 교체는 도감 선택으로 이동. 해제는 확인 후 실행 |

- 소환 해제 안내는 도감 등록과 육성 기록이 유지됨을 명시한다.
- 저장 실패 시 기존 배치를 유지한다. 확인창에서 재시도·취소를 제공한다.
- 숨김과 소환 해제는 별개다. 숨김 조작에 확인창을 요구하지 않는다.
- 무료 밥 주기를 유지한다. 먹이 상품·별명·모습·에버스톤 조작은 만들지 않는다.
- 크기 1~6은 기존 미확정 제안의 UI 예시다. 저장 규칙과 실제 배율은 확정하지 않는다.
- 진화 실행 조건과 도구 소모 규칙은 미확정이다. 상세에서는 조건 확인 진입을 제공한다.

## 토큰과 컴포넌트 범위

- 기존 `S5 Tokens` Light 모드를 확장한다. 별도 테마와 그림자를 추가하지 않는다.
- 상태 안내 배경·문자, 경계선·포커스 굵기에 필요한 토큰만 추가한다.
- 모든 새 토큰에 범위와 WEB 표기를 설정한다. WEB 표기는 구현 예정 이름이며 실제 CSS 연결은 아니다.
- 새로운 상세 컴포넌트는 기존 Components 페이지의 별도 영역에 배치한다.
- TEXT·BOOLEAN·INSTANCE_SWAP 속성을 제공한다. 공통 버튼은 중첩 인스턴스로 재사용한다.
- `Detail / Section Header`는 `Label` TEXT 속성만 제공한다. `S5/Type/Heading`과 `color/ink`를 사용한다. 새 변수와 새 글꼴 스타일은 만들지 않는다.

## 위험과 수용 검사

- 기존 사용자 원본과 파티 화면의 시각 디자인을 유지한다.
- 새 화면은 720×780을 기준으로 한다. 내용이 넘치면 본문 스크롤을 사용한다.
- 상세와 확인창의 캡처에서 잘림·겹침·누락 그림을 확인한다.
- 글꼴, 변수 참조, 컴포넌트 연결, 상태 수, 실제 친밀도 막대 비율을 확인한다.
- 상태를 색만으로 전달하지 않는다. 버튼 이름과 설명을 함께 제공한다.
- 소환 해제 실패 시 기존 포켓몬이 유지되는 화면 흐름을 확인한다.
- 문서 검사와 자산 JSON 파싱 후 커밋·푸시한다. 런타임 변경이 없어 앱 검사는 실행하지 않는다.

## 결과

- 상태 안내, 프로필, 돌봄, 크기 단계·선택, 설정 행, 확인창을 Components 페이지에 만들었다.
- 반복 구역 제목을 위한 `Detail / Section Header` 컴포넌트 `62:227`를 추가했다. 새 변수와 글꼴 스타일은 추가하지 않았다.
- 상세 상태 토큰 8개를 추가했다. 공통 변수와 상세 변수를 합쳐 총 47개다.
- 기존 Outfit·Inter 스타일과 Button·Friendship Bar·숨김 몬스터볼을 재사용했다.
- 상세용 [자산 목록](figma-s5-detail-inventory.json)을 기록했다.
- `S5 / Detail / Base` `64:320`, `Hidden` `69:435`, `Care Success` `69:577`, `Dismiss Confirm` `70:639`, `Dismiss Save Error` `70:692`를 Screens 페이지에 조립했다.
- 본문 `Content / Detail`은 720×638px 세로 스크롤 영역이다. 상세 섹션은 795.98px 높이다.
- 파티 카드에서 상세로 이동한다. 밥 주기, 표시 숨김, 소환 해제 확인·실패 상태의 대표 이동을 연결했다.
- 기본·숨김·성공·확인·실패 화면을 캡처로 확인했다. 다이얼로그 오버레이의 자동 레이아웃 축소와 스크림 불투명도는 발견 후 수정했다.
- 런타임 구현은 미시작이다.
- 크기 선택의 프로토타입 이동 연결은 Figma 세트 내부 목적지 제약으로 보류했다. 컴포넌트 상태와 값은 검수했다.
- 도감·상점·가방·설정용 컴포넌트와 별도 페이지는 이번 범위에서 만들지 않았다.
