- 범위: `pokebuddy companion` 실행 문법에서 포켓몬 이름을 제거했다.
- 결과: `pokebuddy companion`만 정식 실행 명령으로 두고, 첫 실행 선택창과 저장된 파티 복원을 사용한다. `companion eevee`는 안내 오류를 낸다.
- 검수: 인자 파서와 도움말·README·설명서를 갱신했다.
- `--pet eevee` 형태도 동반자 명령에서 거부한다.

다음 작업부터 아래 순서를 지킨다.

1. 설계: 목표, 범위, SSOT, 위험, 통과 조건을 적는다.
2. 작업: 코드와 기능별 문서를 함께 바꾼다.
3. 검수: 실행한 명령과 결과를 적는다.
4. 피드백: 실패와 미확정 항목을 적는다.

커밋 전에는 관련 문서의 상태, 검수 결과, 커밋 ID를 이 파일에 갱신한다.
