## 위험과 확인 기준

- 기존 컴포넌트 연결과 사용자 편집을 보존한다.
- 표시·숨김 카드에서 그림자와 아이콘 위치를 캡처로 확인한다.
- 버튼·메뉴 상태를 분리하고 색·간격·모서리를 변수에 연결한다.
- 파티 화면은 720×780 기준, 두 열과 여섯 칸으로 확인한다.
- Figma 구조와 캡처를 검수한다. 기능 코드를 변경하지 않아 런타임 검사는 범위 밖이다.
