8개 파일을 이동했다. 설계와 현황은 각각 사본을 보관했다. 이동·복사 직후 SHA-256 일치를 확인했다.
이후 상대 링크를 새 위치에 맞췄다. HTML에 보관 안내를 추가했다. JSON 관측값과 과거 날짜별 검수 결과는 변경하지 않았다.
정리 범위와 검증 결과는 [정리 검수](../../work/s5-record-cleanup/review.md)에 있다.
