# S5 기존 작업 기록 정리 검수

## 범위와 판정

| 대상 | 판정과 조치 |
|---|---|
| 이전 S5 계획 3개·검수·피드백 | 현행 기준에서 제외했다. `archive/s5-legacy/`로 이동했다. 날짜별 발견과 수정 기록은 유지했다. |
| 이전 JSON 목록 2개 | 과거 자산 근거로 보관했다. 관측값은 변경하지 않았다. |
| HTML 시안 | 과거 흐름 검토용으로 보관했다. 상단에 보관 안내와 현행 검수 링크를 추가했다. |
| `design.md` | 현재 구조·규칙·S5 목표로 정리했다. 불완전한 저장 예시와 미구현 모듈 트리, 오래된 미확정 숫자를 현행 지시에서 제거했다. 정리 전 사본을 남겼다. |

## 피드백과 수정

| 발견 | 수정 결과 |
|---|---|
| 현재 계획에 눈 아이콘과 1040×760 제안이 남아 있었다. | 닫힌 몬스터볼 상태 표시와 상세 조작으로 바꿨다. Figma 720×780 기준을 반영했다. Electron DIP·최소 크기는 미확정으로 구분했다. |
| S3 구현 후에도 S2 적립 중단·환율 미확정 서술이 설계에 남아 있었다. | 현행 코드 규칙과 S3 검수를 연결했다. 오래된 예시는 보관했다. |
| 다섯 탭의 배치가 아직 제안으로 기록되어 있었다. | v2 내비게이션 5종을 반영했다. 네 탭 본문은 미제작임을 명시했다. |
| 이전 HTML의 동작이 현재 시안의 규칙처럼 적혀 있었다. | 중복 소환·재구매·도구 대상은 미확정 또는 제안으로 구분했다. 현재 Figma는 정적 화면임을 명시했다. |
| 이전 완료 기록과 현재 열린 문제가 섞였다. | 과거 기록을 보관하고 현재 12개 열린 항목을 유지했다. |

문서 검사 스크립트는 이번 검수를 위한 임시 파일이다. 실제 게임 저장이나 훅을 읽거나 쓰지 않았다.
기존 사용자 변경인 `.gitignore`는 유지했다. 코드 변경이 없으므로 빌드·린트·런타임 자체 검사는 실행하지 않았다.
문서 정리에서 발견한 항목은 수정했다. 아래 Figma·기능 후속 작업과 구분한다.

## 남은 작업

이번 정리로 Figma의 열린 항목을 해결한 것으로 처리하지 않는다. [V2-01~V2-12](../s5-design-system-v2/feedback.md)는 모두 열려 있다.
S5 기능 구현과 저장 이식은 미시작이다. 실제 앱의 별명·모습·먹이·에버스톤 제거는 이식 계약 확정 후 처리한다.
