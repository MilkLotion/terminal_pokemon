# S5 기존 작업 기록 정리

날짜: 2026-09-21. 상태: 문서·시안 정리 완료. 검증 결과는 [정리 검수](review.md)를 따른다.

## 목표와 범위

- 두 공유 대화와 Figma 00~05 검수 결과를 기준으로 기존 저장소 기록을 정리한다.
- 현재 설계·현황·기능 계획에서 대체된 스타일과 완료 상태를 제거한다.
- 이전 S5 문서, HTML 시안, 자산 목록은 `docs/archive/s5-legacy/`로 이동한다.
- 날짜가 있는 검수·작업 이력은 보존한다. 이동한 파일의 상대 링크를 갱신한다.
- `docs/`, 루트·확장 README, 패키지 설정, 코드의 문서·시안 참조를 검색한다.
- 실행 중인 S4 기능, 실제 저장, 훅, Figma 원본, 로고·그림 원본은 변경하지 않는다.

## 기준과 위험

- 결정은 [design.md](../../design.md), 상태는 [progress.md](../../progress.md), 기능 계약은 [plan-s5.md](../../specs/s5.md)를 따른다.
- 현재 시각 속성과 미해결 문제는 [v2 검수](../s5-design-system-v2/review.md), [v2 피드백](../s5-design-system-v2/feedback.md)에 있다.
- 기존 문서의 임시값·초기 설계 예시는 현재 코드의 확정 규칙을 덮어쓰지 않는다.
- Figma의 예시 친밀도 100, 크기 단계, 레벨은 런타임 규칙 확정으로 취급하지 않는다.
- 이미 변경된 `.gitignore`와 이전 검수 문서를 보존한다. 실제 앱 기능은 이번 작업에서 이식하지 않는다.

## 수용 검사

- 현재 기능 계획에 눈 아이콘이나 1040×760 화면을 사용하는 지시가 없어야 한다.
- S3·S4 구현과 S5 미구현을 명시한다. S2 당시의 적립 중단 지시를 현재 설계에 남기지 않는다.
- 현재 문서에서 이전 시안으로 연결하는 링크는 과거 기록임을 표시한다.
- 전체 Markdown의 상대 파일 경로와 HTML 내부 파일 링크를 확인한다.
- 현재·과거 JSON 자산 목록을 파싱한다. 현재 자산 수와 열린 검수 항목은 유지한다.
- 파일 이동 전후 내용과 런타임 파일의 변경 여부를 확인한다.
- `git diff --check`를 실행한다. 코드 변경이 없으므로 빌드·린트·런타임 자체 검사는 실행하지 않는다.
