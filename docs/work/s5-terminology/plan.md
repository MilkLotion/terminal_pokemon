# S5 명칭과 기능 출처 정정

날짜: 2026-09-21. 상태: 문서 정정 완료. 미확인 기능의 채택은 미정이다. 기능 구현 미시작.

## 목표와 범위

사용자는 에버스톤을 구상한 적이 없다고 정정했다. 기존 구현과 문서에 등장한다는 이유로 사용자 결정으로 취급한 내용을 바로잡는다.
명칭 교체와 기능 채택을 구분한다. 다른 포켓몬 용어로 자동 치환하지 않는다.
현재 명칭 사전·S5 계획·설계·현황과 과거 기록의 안내를 정정한다. 실행 코드와 저장 데이터는 변경하지 않는다.

## 기준과 위험

- 현재 사용자 정정을 가장 먼저 적용한다.
- 두 공유 대화의 사용자 발언과 기존 코드·문서를 구분해서 확인한다.
- Figma 관측 목록은 일부 속성만 담는다. 목록에 문자열이 없다는 이유로 Figma 전체에서 없다고 단정하지 않는다.
- 에버스톤의 사용자 구상 부정은 다른 모든 기능의 폐기 지시가 아니다.
- 민트·진화의돌·랜덤알·이로치 도구도 직접 채택 근거가 확인되지 않으면 확정 명칭으로 안내하지 않는다.
- 기존 코드의 `everstone` 필드는 정정 작업에서 삭제하지 않는다.

## 수용 검사

- 현행 문서에 에버스톤을 사용자 결정이나 채택할 기능으로 기록하지 않는다.
- 미확인 상품의 명칭과 효과를 확정 목록에서 분리한다.
- 과거 사용자 결정 표기는 날짜가 있는 정정 기록과 연결한다.
- 문서 상대 링크와 `git diff --check`를 확인한다.
- 코드 변경이 없으므로 빌드·린트·런타임 검사는 실행하지 않는다.
