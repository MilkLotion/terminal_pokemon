# S5 명칭과 기능 출처 검수

날짜: 2026-09-21. 상태: 잘못된 귀속 정정 완료. 미확인 기능의 채택은 미정이다.

## 확인한 근거

사용자는 이번 대화에서 에버스톤을 구상한 적이 없다고 밝혔다. 이 정정이 과거 문서의 사용자 결정 표기보다 우선한다.

| 근거 | 확인 결과 | 해석 범위 |
|---|---|---|
| [첫 공유 대화](https://chatgpt.com/share/6aaffb44-3534-83ee-874e-9a63888658eb) | 사용자 메시지 2개는 스크롤·메뉴 아이콘·레이아웃·선택 효과에 관한 내용이다. | 상품 기능을 직접 요청한 근거를 찾지 못했다. |
| [추가 공유 대화](https://chatgpt.com/share/6aaffe73-d0e0-83ee-8d3c-8a674cbcb916) | 사용자 메시지 2개는 다음 작업 진행 요청이다. | 이 발언만으로 별도 상품 기능을 사용자 구상이라 하지 않는다. |
| [상품 자료](../../../data/shop.json) | `mint`, `berry`, `everstone`, `shiny` 가격이 있다. | 기존 구현 사실이다. 사용자 채택 근거가 아니다. |
| [한국어 문구](../../../lib/i18n/ko.json) | `game.everstone`과 진화 제한 안내가 있다. | 에버스톤이 실제 코드에 들어간 사실만 확인한다. 누가 처음 제안했는지는 확정하지 않는다. |
| [S4 계획](../s4/plan.md)과 이전 S5 문서 | 상품명과 효과, 사용자 결정 표기가 있다. | 원래 사용자 발언 없이 문서의 자기 주장을 승인 증거로 사용하지 않는다. |
| v2 관측 JSON 2개 | 해당 상품 문자열은 검색되지 않았다. | 부분 속성 목록이므로 Figma 전체에 없다고 단정하지 않는다. |

## 정정과 남은 항목

| 항목 | 결과 |
|---|---|
| 에버스톤 | 사용자 구상으로 취급한 기록을 정정했다. S5 요구사항에서 제외했다. 다른 명칭으로 치환하지 않았다. |
| 민트·진화의돌·랜덤알·이로치 도구 | [스펙 미확정] 확정 명칭과 기능에서 분리했다. 이름뿐 아니라 기능 채택 자체를 확인해야 한다. |
| 특성 | `Traits` 조합을 사용자 용어로 번역한 혼동을 정리했다. 내부 설명을 타입·성격 조합으로 적었다. 원작의 특성 기능을 추가하지 않았다. |
| 디버프·이로치 | [스펙 미확정] 기존 문서의 용어와 사용자 채택을 구분했다. 화면 명칭과 효과를 확정한 것으로 취급하지 않는다. |
| 기존 코드·저장 | 유지했다. 명칭 출처 정정으로 사용자 데이터를 삭제하지 않았다. |

다른 모든 기능을 사용자가 거절했다고 해석하지 않는다. 추가 후보는 채택 근거가 확인되지 않았다는 뜻이다.
사용자의 구상과 필요한 기능을 정한 뒤 화면 명칭을 정한다. 원작의 상품명을 먼저 고르고 기능을 끼워 넣지 않는다.

## 검증

- 두 공유 대화에서 사용자 메시지와 해당 상품 문자열을 다시 확인했다.
- 현행 명칭·계획·설계·현황의 잘못된 귀속과 단정 표현을 수정했다.
- 과거 이력은 지우지 않았다. 날짜가 있는 정정과 보관 안내를 추가했다.
- 문서 검사 `node $env:TEMP/pokebuddy-cleanup-check.cjs`를 통과했다. 문서 39개에서 상대 링크 302개를 확인했다. 누락은 0개다. JSON 4개도 파싱했다.
- `git diff --check`를 통과했다.
- 코드 변경이 없으므로 빌드·린트·런타임 검사는 실행하지 않았다.
