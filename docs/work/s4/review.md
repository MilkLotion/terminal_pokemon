# S4 검수와 수정 기록

기준: `a8d348fb29cdd430d6dc072f18dbfe0aa37b26a7`.
검수일: 2026-09-18. 환경: Windows.
범위: 겹침 수정과 S4. 사용자가 이 범위를 선택했다.
절차와 가격은 [계획](plan.md)에 있다.

## 구현 결과

- 충돌 밀어내기와 시작 시 자리 벌리기를 제거했다.
- 소환 순서대로 그린다. 드래그와 모습 변경은 순서를 유지한다.
- 해금, 기록, 알림, 진화 없는 종의 단계 보상을 연결했다.
- 파티 칸, 새 종, 민트, 먹이, 에버스톤, 색 구매를 구현했다.
- 친밀도, 시간대, 대상 마리, 에버스톤을 확인한 뒤 진화한다.
- 진화 후 새 그림과 빛 고리를 표시한다.
- 같은 진화 사슬에서 해금한 모습과 구매한 색을 선택할 수 있다.
- 메뉴와 `pokebuddy game`을 연결했다. 전체 설정창은 S5다.
- 저장 v2를 유지한다. 구매 권리와 단계 보상 이력은 기존 inventory와 acc에 기록한다.

## 검토에서 찾은 문제와 수정

| 문제 | 수정 | 검사 |
|---|---|---|
| 그림 다운로드는 기존 2초 응답 제한보다 오래 걸릴 수 있다 | 그림을 사용하는 명령은 최대 45초까지 기다린다. 40초가 지난 거래는 반영하기 전에 거절한다 | 만료된 거래에서 포인트와 상태가 그대로 유지되는지 검사했다 |
| 그림을 기다리는 동안 파티 칸 수나 잠금 소유자가 바뀔 수 있다 | 최신 저장 기준으로 조건과 그림을 다시 확인한다 | 칸이 줄거나 잠금을 잃으면 거래를 거절하는지 검사했다 |
| 잠금을 잃은 서버가 자기 mailbox에 요청을 다시 보낼 수 있다 | 서버가 잠금을 잃으면 요청을 다시 보내지 않는다. 대신 실패를 반환한다 | 서버가 자기 자신에게 요청을 다시 보내지 않는지 검사했다 |
| 숨기기 명령은 저장에 실패해도 성공을 반환했다 | 표시 상태를 복원한 뒤 실패를 반환한다 | 저장 경로를 임시 디렉터리로 바꿔 실패를 재현했다 |
| 에버스톤을 해제한 뒤 다시 구매하면 포인트를 중복으로 뺄 수 있다 | 구매 권리는 보존한다. 재장착은 무료다. 중복 구매는 거절한다 | 해제와 재장착 후 포인트가 그대로인지 검사했다 |
| 실패한 그림 로딩 결과를 계속 캐시했다 | 성공한 그림만 캐시한다 | 코드를 검토했다. 그림이 실패하면 거래를 취소하는지 검사했다 |
| 누적 포인트가 늘어도 상점 메뉴는 이전 값을 그대로 보여줬다 | 정수 포인트가 바뀌면 메뉴를 갱신한다 | 코드를 검토했다 |
| PowerShell에서는 JSON 인자의 따옴표 처리가 다를 수 있다 | `key=value` 형식 인자를 추가했다 | 실제 CLI와 임시 HOME으로 왕복 검사를 했다 |

## 자동 검사

- `npm run check` 명령으로 메인과 렌더러 타입 검사를 통과했다.
- `npm run selftest` 명령으로 저장, 도감, 에이전트, 추적, 움직임, 무대, 상태, S4 검사 8벌을 통과했다.
- 무대 검사는 6마리를 같은 위치에 두는 경우, 반복 틱, 드래그, 재소환, 목록 재정렬, 그림 교체, 화면 경계를 확인했다.
- S4 검사는 파티 상한, 잔액 부족, 잘못된 성격, 진화 분기와 밤 조건, 에버스톤, 다른 사슬 거절을 확인했다.
- 저장 검사는 색 구매 권리, 단계 보상 중복 방지, 먹이 소비, 저장 실패 복원, 잠금 상실을 확인했다.
- CLI 검사는 별도 Node 프로세스가 임시 HOME의 mailbox로 snapshot을 요청하고 결과를 읽는 것을 확인했다.

## 화면 검사

숨긴 Electron 창에서 실제 렌더러를 실행했다. 사용자의 게임 저장은 사용하지 않았다.

- 겹친 픽셀에서 나중에 소환한 마리의 색을 확인했다.
- 앞 그림의 투명 부분에서 뒤 그림과 뒤 마리의 클릭 대상을 확인했다.
- 우클릭 이벤트가 앞 마리를 선택하는지 확인했다.
- Electron에서 상점, 파티, 도감 메뉴를 실제로 생성했다.
- PMD 서버에서 이브이 일반색, 이브이 다른 색, 블래키 그림을 임시 폴더로 받았다.
- 각 그림의 캔버스 픽셀과 화면 캡처를 확인했다.
- 일반색과 다른 색은 각각 24개 동작, 블래키는 20개 동작을 읽었다. 저작자 기록도 읽었다.

다른 색 경로는 SpriteCollab의 [이브이 그림 폴더](https://github.com/PMDCollab/SpriteCollab/tree/master/sprite/0133/0000/0001)를 확인했다.
실제 로더는 `<도감번호>/0000/0001` 경로를 사용한다. 그림이 없으면 구매를 거절한다.

## 남은 확인

- Windows 125%와 150% DPI에서 실제 창의 드래그와 클릭 통과를 아직 확인하지 않았다.
- 앱 전환, 다중 화면, 운영체제 알림 표시, 6마리일 때 CPU와 GPU 사용량을 아직 확인하지 않았다.
- macOS 실기 회귀 검사를 아직 하지 않았다.
- 모든 종과 특수 폼에 PMD 그림이 있는지 아직 확인하지 않았다. 기존 로더는 도감번호의 기본 폼을 사용한다.

숨긴 창 검사는 운영체제의 실제 입력과 성능 검사를 대신하지 않는다.
가격과 보상은 조정 가능한 초기값이다. 사용자의 확정값으로 기록하지 않았다.
