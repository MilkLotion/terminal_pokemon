# 작업 기록 목록

현재 상태는 [progress.md](../progress.md)를 따른다. 새 작업의 기록 방식은 [작업 절차](../contributing/workflow.md)를 따른다.

| 작업 | 기록 |
|---|---|

| S3 육성 | [검수](s3/review.md) |
