# S4 검수와 수정 기록

기준: `a8d348fb29cdd430d6dc072f18dbfe0aa37b26a7`.
검수일: 2026-09-18. 환경: Windows.
범위: 겹침 수정과 S4. 사용자가 이 범위를 선택했다.
절차와 가격은 [계획](plan-s4.md)에 있다.

## 구현 결과

- 충돌 밀어내기와 시작 시 자리 벌리기를 제거했다.
- 소환 순서대로 그린다. 드래그와 모습 변경은 순서를 유지한다.
- 해금, 기록, 알림, 진화 없는 종의 단계 보상을 연결했다.
- 파티 칸, 새 종, 민트, 먹이, 에버스톤, 색 구매를 구현했다.
- 친밀도, 시간대, 대상 마리, 에버스톤을 확인한 뒤 진화한다.
- 진화 후 새 그림과 빛 고리를 표시한다.
- 같은 진화 사슬에서 해금한 모습과 구매한 색을 선택할 수 있다.
- 메뉴와 `pokebuddy game`을 연결했다. 전체 설정창은 S5다.
- 저장 v2를 유지한다. 구매 권리와 단계 보상 이력은 기존 inventory와 acc에 기록한다.

## 검토에서 찾은 문제와 수정

| 문제 | 수정 | 검사 |

| 그림 다운로드가 기존 2초 응답 제한보다 길 수 있음 | 그림을 사용하는 명령은 최대 45초 대기. 40초가 지난 거래는 반영 전 거절 | 만료된 거래의 포인트와 상태 유지 |
| 그림을 기다리는 동안 파티 칸이나 잠금 소유자가 바뀔 수 있음 | 최신 저장으로 조건과 그림을 다시 확인 | 칸 감소와 잠금 상실 후 거래 거절 |
| 잠금을 잃은 서버가 자기 mailbox에 다시 요청할 수 있음 | 서버가 잠금을 잃으면 재전송하지 않고 실패 반환 | 자기 재전송 방지 검사 |
| 숨기기 저장 실패에도 성공을 반환함 | 표시 상태 복원 후 실패 반환 | 저장 경로를 임시 디렉터리로 바꿔 실패 재현 |
| 에버스톤 해제 후 재구매하면 중복 차감 가능 | 구매 권리 보존. 재장착 무료. 중복 구매 거절 | 해제와 재장착 후 포인트 유지 |
| 실패한 그림 로딩을 계속 캐시함 | 성공한 그림만 캐시 | 코드 검토. 그림 실패 시 거래 취소 검사 |
| 누적 포인트가 늘어도 상점 메뉴가 이전 값을 유지함 | 정수 포인트가 바뀌면 메뉴 갱신 | 코드 검토 |
| PowerShell에서 JSON 인자 따옴표 처리가 달라질 수 있음 | `key=value` 인자 추가 | 실제 CLI와 임시 HOME 왕복 검사 |

## 자동 검사

- `npm run check`: 메인과 렌더러 타입 검사 통과.
- `npm run selftest`: 저장, 도감, 에이전트, 추적, 움직임, 무대, 상태, S4의 8벌 통과.
- 무대 검사: 6마리 같은 위치, 반복 틱, 드래그, 재소환, 목록 재정렬, 그림 교체, 화면 경계.
- S4 검사: 파티 상한, 잔액 부족, 잘못된 성격, 진화 분기와 밤 조건, 에버스톤, 다른 사슬 거절.
- 저장 검사: 색 구매 권리, 단계 보상 중복 방지, 먹이 소비, 저장 실패 복원, 잠금 상실.
- CLI 검사: 별도 Node 프로세스가 임시 HOME의 mailbox로 snapshot을 요청하고 결과를 읽음.

## 화면 검사

숨긴 Electron 창에서 실제 렌더러를 실행했다. 사용자의 게임 저장은 사용하지 않았다.

- 겹친 픽셀에서 나중에 소환한 마리의 색을 확인했다.
- 앞 그림의 투명 부분에서 뒤 그림과 뒤 마리의 클릭 대상을 확인했다.
- 우클릭 이벤트가 앞 마리를 선택하는지 확인했다.
- Electron에서 상점, 파티, 도감 메뉴를 실제로 생성했다.
- PMD 서버에서 이브이 일반색, 이브이 다른 색, 블래키 그림을 임시 폴더로 받았다.
- 각 그림의 캔버스 픽셀과 화면 캡처를 확인했다.
- 일반색과 다른 색은 각각 24개 동작, 블래키는 20개 동작을 읽었다. 저작자 기록도 읽었다.

다른 색 경로는 SpriteCollab의 [이브이 그림 폴더](https://github.com/PMDCollab/SpriteCollab/tree/master/sprite/0133/0000/0001)를 확인했다.
실제 로더는 `<도감번호>/0000/0001` 경로를 사용한다. 없는 그림은 구매를 거절한다.

## 남은 확인

- Windows 125%와 150% DPI에서 실제 창의 드래그와 클릭 통과.
- 앱 전환, 다중 화면, 운영체제 알림 표시, 6마리 CPU와 GPU 사용량.
- macOS 실기 회귀 검사.
- 모든 종과 특수 폼의 PMD 그림 제공 여부. 기존 로더는 도감번호의 기본 폼을 사용한다.

숨긴 창 검사는 운영체제의 실제 입력과 성능 검사를 대신하지 않는다.
가격과 보상은 조정 가능한 초기값이다. 사용자의 확정값으로 기록하지 않았다.
