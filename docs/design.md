# pokebuddy 설계 v2 — 무대 하나, 다섯 마리, 성격

> 2026-09-17 재설계. 1판(세션 펫 → 동반자)의 결정은 그대로 두고, 게임 구조를 "한 마리" 에서 **무대 하나에 최대 5마리, 마리마다 성격·상태** 로 바꾼다.
> 코드는 기능별 모듈로 나눠 **TypeScript** 로 다시 짠다. 구현은 이 문서가 확정된 뒤에 시작한다.
> 지금 동작(0.3.0)의 설명은 [guide.md](guide.md). 1판 원문은 git 이력에.
> 숫자는 전부 자리표시자 — 규칙표 한 곳에 두고 써 보며 고친다.

## 결정 (누적)

| 항목 | 결정 | 이유 · 비고 |
|---|---|---|
| 제품 형태 | 상주 Electron 앱 + 얇은 VS Code 확장 | 1판. 앱이 런타임·저장·설정창, 확장은 센서·런처·설정 미러 |
| 실행 형태 둘 | 독립 실행 `pokebuddy companion` 은 **항상 위**, 확장 기동은 **그 VS Code 창 안에서만** | 1판. M1 구현 완료 |
| 기존 세션 펫 | `!pokebuddy <종>` 은 샌드박스로 유지 — 게임 없음 | 1판 |
| **화면 구조** | **무대 하나** — 따라가는 창 크기의 투명 창 하나에 최대 5마리를 함께 그린다 | 마리마다 프로세스면 5마리도 수백 MB 에 창 추적 다섯 번. 무대 하나면 한 번이고, 펫들이 서로 보고 모일 수 있다 |

| **성격** | **원작 25개 성격 그대로.** 얻을 때 무작위, 상점의 민트로 바꿈. 성격 하나 = 다섯 축 값 | 사용자가 이미 아는 이름. "활발함" 설정을 대신한다 |
| **모듈** | 움직임 · 상태 · 도감/해금 · 상점 · 커맨드 처리기 · 저장 · 창 추적 · 화면 — 기능별로 나눈다 | 모듈은 자기 데이터만 소유, 커맨드 처리기만 여러 모듈을 잇는다 |
| **TypeScript** | `src/` 에 새 구조로 다시 짜며 TS. `tsc` 하나, 번들러 없음. `allowJs` 로 옛 JS 와 섞어 두고 하나씩 옮긴다 | 그대로 쓸 것(창 추적·판정·저장)은 옮기며 타입만, 다시 짤 것(움직임·상태·화면)은 TS 로 바로 |
| **종 프로필** | PokeAPI 데이터에서 1089종 기본값 + 손으로 다듬는 종만 override JSON | 1089종을 손으로 쓸 수 없다 |
| **메뉴 최소** | 우클릭 = 그 펫 한 줄 · 밥 주기 · 놀아주기 · 설정… · 종료. 트레이 = 설정… · 종료. **숨기기·고스트 모드·크기·성격은 전부 설정창** | "최대한 간단한 정보만, 설정에서 최대한 다" |
| **에이전트 연결** | 설정창 "연결" 탭에 Claude Code · Codex · Gemini **버튼을 따로**. 누르면 그 CLI 에 훅 등록, 옆에 연결 상태와 오늘 토큰 | 지금 `pokebuddy setup` 이 한 번에 하던 등록을 CLI 별로 |
| **토큰 → 친밀도·포인트** | 훅이 턴이 끝날 때 **토큰 사용량**을 읽어 적고, 상태 모듈이 친밀도와 포인트로 바꾼다. 토큰을 못 읽는 CLI 는 일한 시간으로 | "일한 양" 의 척도. CLI 별 읽기 가능성은 확인 필요 |
| **모습 선택** | 마리마다 **보이는 그림**을 도감에 해금된 모습(같은 진화 사슬 + 색) 중에서 고른다. 진화 단계·친밀도는 그대로 | 진화한 뒤 이전 모습을 원할 수 있다. 도감 해금이 곧 선택지 |
| 첫 화면 | 첫 실행만 스타터 선택 창, 이후엔 펫 + 트레이 | 1판 |
| 설정창 기술 | 바닐라 HTML · CSS (TS 로 컴파일한 ESM) | 1판. 빌드 도구는 tsc 뿐 |
| 친밀도 | 감소 없음. 기분·배고픔만 오르내림. 원천은 전부 — 켜 두기·밥·놀기·찌르기·에이전트가 일한 시간·턴 완료 | 1판 + 배고픔 추가 |
| 문구 | 호칭 없이 동사만 · 종료 · 담담한 설명 · 기분은 말로 · 안 되는 항목은 이유를 항목에 · 설정 라벨은 두세 글자 명사 · "게임 켬/끔" 없음 | 1판. `lib/i18n/<언어>.json`, 이름은 `lib/names.json` |
| 언어 | 기본 ko, en 준비 | 1판 |

## 한 문장

터미널 창 위의 투명한 무대에 내 포켓몬들이 각자 성격대로 돌아다니고, 내가 개발하는 동안 친해지고, 배고프면 밥을 달라 하고, 친밀도가 차면 진화하며, 조건을 채우면 새 종이 해금된다.

## 화면 — 무대 (stage)

| 항목 | 설계 |
|---|---|
| 창 | 투명 BrowserWindow 하나. 크기는 **따라가는 창과 같다**(지금은 펫 몸 크기). 독립 실행은 맨 앞 터미널 창을 따르고 항상 위, 창 모드는 그 VS Code 창 바로 위 — 1판 판정(`lib/follow` · `lib/state`) 그대로 |
| 그리기 | 캔버스 하나에 N마리. 마리마다 위치·방향·현재 동작·배율(크기). 프레임 타이머 하나, 시트는 미리 디코드 |
| 클릭 | 픽셀 히트로 "어느 펫인가" 를 정한다 (겹치면 위에 그린 것). 그림 없는 곳은 아래 창으로 통과 — 지금 `hit` 메커니즘을 마리 단위로 확장 |
| 드래그 | 그 펫만 옮긴다. 자리(집)는 마리별로 저장 |
| 모임 | 사교성이 높은 펫은 다른 펫 근처로 가고, 낮은 펫은 거리를 둔다. 같은 자리에 겹치면 살짝 밀어낸다 |
| 표시 | 마리마다 "화면에 보임" 토글(설정창). 파티에는 있지만 안 보이는 마리도 상태는 흐른다 |
| 여러 창 | 창 모드에서 창이 여럿이면 무대도 여럿 — 파티 전원이 각 무대에 다 나올지, 창마다 나눌지 [스펙 미확정] |
| 확인 필요 | 큰 투명 창의 클릭 통과·GPU 부담(mac · Windows). 5마리 × 25fps 캔버스는 무리 없을 것으로 본다 |

## 모듈 — `src/` 와 `data/`

```
src/
├─ main/                Electron 메인 — 앱 수명, 무대 창, 트레이, 설정창, IPC
│  ├─ app.ts            기동·모드·단일 인스턴스·종료
│  ├─ stage-window.ts   무대 창 만들기·따라가기·클릭 통과·z-order   (지금 main.js 의 창 부분)
│  ├─ tray.ts · menus.ts · settings-window.ts · picker-window.ts
│  └─ commands.ts       커맨드 처리기 — 우클릭·트레이·설정창·CLI·확장의 요청을 한 곳에서 받아 모듈에 분배
├─ follow/              창 추적·에이전트 판정                        (지금 lib/follow.js · lib/state.js — 옮기며 타입만)
├─ agents/              에이전트 연결 — CLI 어댑터(claude · codex · gemini): 훅 등록·해제, 연결 상태, 토큰 사용량 읽기  (지금 cli/setup.js TARGETS · src/hooks/pokebuddy-state.ts)
├─ motion/              움직임 — 마리별 brain, 성격 파라미터, 먹기·커서 반응·모임·드래그
├─ state/               상태 — 마리별 배고픔·기분·친밀도·잠, 종 프로필 + 성격 축, 하루 상한, 날짜 리셋
├─ dex/                 도감 — 종 프로필·해금 조건·진화·이름 (data/*.json 읽기, 판정기)
├─ shop/                상점 — 포인트·가격표·구매·민트·슬롯
├─ save/                저장 v2·잠금·mailbox                          (지금 game/save.js · writer.js · mailbox.js — 옮기며 타입)
├─ renderer/            무대 캔버스·스프라이트·히트, 설정창·스타터 화면  (ESM TS)
├─ cli/                 pokebuddy 명령                                (지금 cli/ — 옮기며 타입)
└─ shared/              타입·i18n·이름·상수·시계
data/
├─ natures.json            25 성격 → 다섯 축
├─ species.defaults.json   PokeAPI 에서 뽑은 기본 프로필 (src/tools/build-species.ts, 빌드 산출물)
├─ species.overrides.json  손으로 다듬은 종 (스타터·자주 보는 종)
├─ unlocks.json            종별 해금 조건

모듈 규칙
- 모듈은 자기 데이터만 소유한다. 다른 모듈의 데이터는 함수로만 읽고 쓴다
- 시각·파일·Electron 은 주입한다 — `motion` · `state` · `dex` · `shop` 은 node 만으로 시험한다 (지금 brain.js · economy.js 의 태도)
- 커맨드 처리기만 여러 모듈을 잇는다. 메뉴·설정창·CLI 는 처리기에 요청을 보내고 결과 코드로 문구를 만든다
- 숫자는 모듈마다 규칙표 하나(`RULES`)에

지금 코드의 자리 — `game/economy.js` 의 규칙표·하루 상한·스트릭은 `state` 의 바탕이 되고, `buddy/brain.js` 의 리듬·산책·반응은 `motion` 의 바탕이 된다. `game/save.js` · `writer.js` · `mailbox.js` 는 `save/` 로 옮긴다. `main.js` 의 창 추적·판정은 `follow/` 와 `stage-window.ts` 로 나뉜다. 렌더러는 한 마리 → 무대로 다시 짠다.

## 성격 — 25개를 다섯 축으로, 축은 배율

이 앱에 능력치는 없다. 원작에서 성격 25개가 "어느 능력치를 올리고 어느 것을 내리나" 로 정의된 것을 **25개 이름을 다섯 축에 나눠 넣는 규칙으로만** 빌린다 — 그래서 25개가 저절로 서로 다른 값이 된다. 앱 안에서 축의 값(+1 · 0 · −1)은 전부 **배율**로 작동한다. 아래 배율은 예시고 숫자는 규칙표(`natures.json`)에서 손본다.

| 축 | 원작에서 빌린 자리 | 오르면 (+1) | 내리면 (−1) |
|---|---|---|---|
| 활동성 | 스피드 | 더 자주·빨리 걷는다. 켜 두기 친밀도 ×1.2. 배고픔 ×1.2 | 오래 서 있다. 켜 두기 ×0.8. 배고픔 ×0.8 |
| 대담함 | 공격 | 커서를 쫓고 클릭에 크게 반응한다. 에이전트 실패에 기분 −2 | 커서를 피한다. 실패에 기분 −8 |
| 안정성 | 방어 | 기분 변동 ×0.7. 잠이 빨리 든다 | 기분 변동 ×1.3. 잠이 늦다 |
| 사교성 | 특수공격 | 다른 펫 옆으로 모인다. 함께 있으면 기분 +, 놀아주기 친밀도 ×1.3 | 거리를 둔다. 혼자여도 기분이 안 떨어진다. 놀아주기 ×0.8 |
| 인내 | 특수방어 | 배고픔 ×0.8. 방치에 기분이 늦게 떨어진다. 밥 친밀도 ×0.8 | 배고픔 ×1.3. 밥 친밀도 ×1.3 |

| 오르는 축 \ 내리는 축 | 대담함 | 안정성 | 활동성 | 사교성 | 인내 |
|---|---|---|---|---|---|
| **대담함** | 노력 | 외로움 | 용감 | 고집 | 개구쟁이 |
| **안정성** | 대담 | 온순 | 무사태평 | 장난꾸러기 | 촐랑 |
| **활동성** | 겁쟁이 | 성급 | 성실 | 명랑 | 천진 |
| **사교성** | 조심 | 온화 | 냉정 | 수줍음 | 덜렁 |
| **인내** | 차분 | 얌전 | 건방 | 신중 | 변덕 |

대각선 다섯(노력·온순·성실·수줍음·변덕)은 축이 0 인 중립 성격 — 변덕만 "가끔 아무 축이나 잠깐 튄다" 를 붙인다. 값은 오르는 축 +1, 내리는 축 −1, 나머지 0 을 기본으로 두고 `data/natures.json` 에 적는다. 얻을 때 무작위로 붙고, 상점의 **민트**로 바꾼다. 화면에는 성격 이름만 보인다(설정창 마리 카드).

## 상태 — 마리별

| 지표 | 범위 | 오르는 것 | 내리는 것 |
|---|---|---|---|
| 배고픔 | 0~100 (높으면 배고프다) | 시간 × 종의 `hungerRate` × (활동성 +, 인내 −) | 밥 −40 |
| 기분 | 0~100 | 밥·놀기·찌르기, 함께 있기(사교성), 에이전트 턴 완료 | 배고픔 70 넘음, 방치, 에이전트 실패(대담함이 낮으면 더), 혼자(사교성 높으면) |
| 친밀도 | 누적, 감소 없음 | 1판 원천 전부 — 켜 두기·밥·놀기·찌르기·**토큰(또는 일한 시간)**·턴 완료. 하루 상한은 마리별 | — |
| 잠 | 잠들기까지 남은 시간 | 입력 없음 × (안정성 +) | 입력·클릭·에이전트 일 시작 |

- 시간 원천(켜 두기·일한 시간·턴 완료)은 **무대에 나온 마리 전원**이 각자 받되 **마리마다 양이 다르다** — 종 프로필의 배율 × 성격 축의 배율 (사용자 결정 2026-09-17: "포켓몬마다 시간에 따른 친밀도가 다르니 그 시간마다 주면 된다"). 밥·놀기·찌르기는 그 마리에게
- **일한 양** — 연결된 에이전트가 토큰을 읽을 수 있으면 토큰(예: 1천 토큰에 친밀도 +1, 1만 토큰에 포인트 +1, 하루 상한), 못 읽으면 `running` 시간(1판). 훅이 `Stop`(턴 끝) 때 사용량을 상태 기록에 `usage: { in, out }` 로 적고, 상태 모듈이 tick 에서 증분을 읽는다. 무대의 전원이 마리별 배율로 받는다
- 배고픔이 높으면 펫이 밥그릇 쪽을 보거나 우클릭 첫 줄이 "배고픔" 을 먼저 말한다. 배고픔 자체는 친밀도를 깎지 않는다
- 종 프로필(`species.defaults.json`) — `affinityRate`(시간 원천 배율), `hungerRate`(체중↑·기본 스피드↑), `sleepiness`(체중↑), `moodBase` · `moodSwing`, `likes`(함께 일하기·놀기·모임 중 무엇에 더 반응하나 — 타입에서 기본값). 뽑는 규칙과 값은 **Claude 가 맡는다**(사용자 결정) — 1089종 기본값을 만들고 스타터 29종은 손으로 다듬어 다섯 종만 표본으로 보인다. 자주 보는 종은 `species.overrides.json` 에

  "ditto":    { "party": { "count": 3 } },
  "lapras":   { "work": { "hours": 100 } },
  "chansey":  { "streak": { "days": 14 } },
  "raichu-alola": { "bond": { "of": "pikachu", "affinity": 1500 }, "shop": 300 }
}
```

| 조건 | 뜻 | 판정에 필요한 것 |
|---|---|---|
| `starter` | 첫 실행 선택 화면에 나온다 | — |
| `evolve` | 그 종을 가진 마리의 친밀도가 임계에 닿으면 그 마리가 바뀐다. `when` 은 시간대 | 마리별 친밀도, 시각 |
| `shop` | 해금된 뒤 포인트로 산다 | 포인트 |
| `party` | 파티 마리 수 | 저장 |
| `work` | 에이전트와 함께 일한 누적 시간 | 통계 `totals.workMs` |
| `streak` | 연속 교감 일수 | 저장 |
| `bond` | 특정 종을 가진 마리의 친밀도 | 저장 |
| `time` · `event` | 시간대·날짜 | 시각 |

- 조건 종류마다 판정 함수 하나 `check(cond, world) → boolean`. `world` = 저장 + 누적 통계 + 시각. 여러 조건이 있으면 전부 만족
- **해금 ≠ 획득.** 해금되면 상점(`shop` 가격이 있으면)이나 무료 획득 목록에 나타난다. `evolve` 만 즉시 — 그 마리의 종이 바뀐다(진화)
- 진화는 `evo.json` 의 사슬을 따르고 분기는 사용자 선택(1판). 에버스톤은 그 마리에 붙는다
- 누적 통계 `totals` 를 저장에 둔다 — `workMs · presenceMs · turns · days · fed · played`

## 커맨드 처리기 — `src/main/commands.ts`

입력 넷(우클릭 · 트레이 · 설정창 IPC · mailbox 파일 = CLI·확장)이 같은 모양 `{ cmd, target?, args, from }` 으로 들어와 모듈에 분배되고, 결과는 코드로 나간다. 문구는 표면(메뉴·설정창·CLI)이 언어 파일로 만든다.

| 명령 | 대상 | 모듈 |
|---|---|---|
| `feed` · `play` · `poke` | 마리 | state (+ motion 에 연출 요청) |
| `evolve` | 마리, 후보 | dex → state |
| `party.show` · `party.hide` · `party.remove` | 마리 | state · stage |
| `pet.set` (크기 · 성격은 민트로만 · 별명) | 마리 | state · stage |
| `pet.look` (모습 · 색 — 해금된 것 중) | 마리 | dex → stage |
| `agent.connect` · `agent.disconnect` | CLI 이름 | agents (훅 등록·해제) |
| `settings.set` (표시 · 고스트 모드 · 잠들기 · 언어 · 자동 시작) | 전역 | main |
| `shop.buy` | 항목, 마리 | shop → dex/state |
| `snapshot` | — | 전 모듈 읽기 |
| `quit` | — | main |
