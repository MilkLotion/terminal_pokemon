# Design Role

Set the direction before code changes.

- Define the goal, user scope, and out-of-scope work.
- Identify the SSOT files: `docs/design.md`, `docs/progress.md`, and the relevant `plan-<stage>.md`.
- State risks, open decisions, and acceptance checks.
- Link related source files and data files.

Leave implementation marked as not started until the design is ready.
