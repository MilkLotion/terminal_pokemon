# 용어사전

갱신: 2026-09-21. 적용 범위: 사용자 화면과 제품 설명의 용어다.
현재 앱은 S4다. S5 기능 구현은 미시작이다.

## 읽는 기준

| 상태 | 의미 |
|---|---|
| 현재 구현 | 코드에서 확인한 개념이다. 사용자 승인 여부를 뜻하지 않는다. |
| 기존 S5 설계 | 현재 설계 문서에 기록된 개념이다. 구현 완료나 개별 사용자 발언 확인을 뜻하지 않는다. |
| [스펙 미확정] | 명칭 또는 기능의 채택을 확인해야 한다. 각 항목에 미정 범위를 적는다. |
| 제외 | S5 화면이나 요구사항에서 제외한 항목이다. 기존 저장의 삭제 지시가 아니다. |

결정은 [현재 설계](design.md)를 따른다. 기능 조건은 [S5 기능 계약](specs/s5.md)을 따른다.
정리 근거와 발견 사항은 [명칭 검수](work/s5-terminology/review.md)에 기록한다.

## 포켓몬과 파티

아래 용어는 기존 S5 설계에 따른다. 근거는 [도감 등록과 파티 소환](specs/s5.md#3-도감-등록과-파티-소환)이다.

| 명칭 | 의미와 사용 규칙 |
|---|---|
| 포켓몬 | 사용자가 도감에서 확인하거나 파티에 소환하는 대상이다. 종과 개별 육성 기록은 문맥에 따라 구분한다. |
| 종 | 도감 등록을 구분하는 포켓몬 종류다. 동일 종의 동시 소환 허용 여부는 미정이다. |
| 파티 | 소환한 포켓몬을 배치하는 전체 구성이다. 최대 여섯 칸으로 구성한다. |
| 파티 칸 | 포켓몬 한 마리를 배치하는 자리다. 파티 전체와 구분한다. |
| 빈 칸 | 사용할 수 있지만 포켓몬을 배치하지 않은 파티 칸이다. |
| 잠긴 칸 | 아직 사용할 수 없는 파티 칸이다. 소환 대상으로 선택할 수 없다. |
| 도감 | 전체 종과 각 종의 등록 상태를 확인하는 화면이다. |
| 도감 등록 | 해당 종을 소환할 수 있는 상태다. 도감 전체 목록에 보이는 것과 구분한다. |
| 미등록 | 도감에 표시되지만 아직 소환할 수 없는 상태다. |
| 소환 | 도감에 등록된 종을 빈 파티 칸에 배치하는 것이다. |
| 교체 | 파티 칸의 포켓몬을 도감에 등록된 다른 종으로 바꾸는 것이다. 이전 종의 등록과 육성 기록은 그대로 유지한다. |
| 소환 해제 | 파티 칸을 비우는 것이다. 도감 등록과 육성 기록은 보존한다. |
| 재소환 | 등록된 종을 다시 소환하는 동작을 설명하는 말이다. [스펙 미확정] 기록 복원과 진화 승계 규칙은 정하지 않았다. |
| 숨기기 | 파티 배치를 유지하면서 포켓몬 표시만 끄는 동작이다. 숨겨도 육성을 유지한다. |
| 다시 표시 | 숨긴 파티 포켓몬의 표시를 다시 켜는 동작이다. 새 소환이나 교체를 뜻하지 않는다. |

숨김 상태는 이미지 영역 우측 위의 작은 닫힌 몬스터볼로 표시한다. 상태 조작에는 툴팁과 접근성 이름을 제공한다.

## 육성과 보상

아래 용어는 현재 구현을 설명한다. 근거는 [성격과 육성](design.md#성격과-육성), [저장 타입](../src/shared/types.ts), [상태 규칙](../src/state/rules.ts)이다.
수치와 계산식은 해당 원본을 따른다. 이 사전에서 새 균형값을 정하지 않는다.

| 용어 | 의미와 사용 규칙 |
|---|---|
| 성격 | 포켓몬의 움직임과 상태에 영향을 주는 분류다. 원작 25개 성격을 사용한다. 타입이나 특성과 구분한다. |
| 친밀도 | 포켓몬별로 누적하는 육성 수치다. 현재 규칙에서는 감소하지 않는다. |
| 배고픔 | 포켓몬이 배고픈 정도를 나타내는 수치다. 값이 높을수록 배고프다. |
| 기분 | 포켓몬의 현재 기분을 나타내는 수치다. 친밀도와 달리 오르내릴 수 있다. |
| 돌봄 | 밥 주기와 놀아주기 같은 상호작용을 묶어 설명하는 말이다. 각 동작의 효과와 제한은 상태 규칙을 따른다. |
| 밥 주기 | 포켓몬의 배고픔을 낮추는 돌봄 동작이다. 먹이 상품 구매와 구분한다. |
| 놀아주기 | 포켓몬과 놀아주는 돌봄 동작이다. 기분과 친밀도에 영향을 준다. |
| 포인트 | 구매에 사용하는 게임 재화다. 친밀도와 구분한다. |
| 토큰 | 연결한 CLI에서 읽는 사용량 단위다. 게임 재화나 Figma 디자인 토큰과 구분한다. |
| 작업 시간 | 토큰을 읽지 못할 때 작업 적립에 사용하는 시간이다. 단순히 앱을 켜 둔 시간과 구분한다. |
| 진화 | 조건을 충족한 포켓몬의 종이 바뀌는 동작이다. S5의 종별 기록 승계는 미정이다. |

## 구매와 사용

근거는 [현재 상점 설계](design.md#상점)와 [S5 상점과 가방](specs/s5.md#6-상점과-가방)이다.

| 용어 | 의미와 사용 규칙 | 상태 |
|---|---|---|
| 해금 | 제한을 풀어 이용할 수 있게 되는 것이다. 종의 구매 조건인지 파티 칸의 사용 조건인지 대상을 적는다. S5 도감 등록과 동일한 뜻으로 쓰지 않는다. | 현재 구현. S5 등록으로 옮기는 기준은 미정이다. |
| 상점 | 포인트로 상품을 구매하는 화면이다. S5는 구매와 사용을 분리한다. | 현재 구현 / 기존 S5 설계 |
| 가방 | 구매한 도구와 알을 보관하고 사용하는 화면이다. | 기존 S5 설계. 개별 상품과 부화 기능의 채택은 미정이다. |
| 도구 | 가방에 보관한 뒤 대상 포켓몬을 골라 사용하는 상품 분류다. | 기존 S5 설계. 개별 도구의 채택은 미정이다. |
| 구매 | 포인트를 지불하고 상품을 얻는 동작이다. | 현재 구현. S5 구매 결과는 상품 계약을 따른다. |
| 사용 | 가방에서 도구의 대상과 옵션을 골라 효과를 적용하는 동작이다. | 기존 S5 설계. 소모 규칙은 개별 상품에서 정한다. |

## 화면과 설정

아래는 기존 S5 설계와 명칭 제안이다. 근거는 [화면 구조](specs/s5.md#2-화면-구조)와 [설정과 연결](specs/s5.md#7-설정과-연결)이다.

| 용어 | 의미와 사용 규칙 |
|---|---|
| 설정창 | 파티 / 도감 / 상점 / 가방 / 설정 탭을 담는 창이다. |
| 설정 | 설정창 안에서 일반 항목과 CLI 연결을 관리하는 탭이다. 설정창 전체와 구분한다. |
| 연결 | CLI의 활동을 앱에서 감지하도록 연결하는 기능이다. 훅 연결 상태와 사용량 감지 상태를 구분한다. |
| 포켓몬 표시 | 기존 '무대 표시' 명칭을 대체한다. 화면 문구에 '무대'라는 말을 쓰지 않는다. |
| 클릭 통과 | [스펙 미확정] 기존 '고스트 모드' 명칭을 대체하는 제안이다. 켜면 포켓몬 뒤의 창을 클릭할 수 있다. |
| 데스크톱에서 사용 | [스펙 미확정] 기존 '동반자 모드' 명칭을 대체하는 제안이다. 내부 식별자 `companion`은 그대로 유지한다. |
| VS Code에서 사용 | [스펙 미확정] 기존 '창 모드' 명칭을 대체하는 제안이다. 내부 식별자 `window`는 그대로 유지한다. |
| 터미널 세션에서 사용 | [스펙 미확정] 기존 '세션 모드' 명칭을 대체하는 제안이다. 내부 식별자 `session`은 그대로 유지한다. |

실행 환경 명칭의 제안은 새 모드 선택 옵션을 추가하는 요구가 아니다.
실행 명령 `pokebuddy companion`은 이번 화면 명칭 변경으로 바꾸지 않는다.

## 내부 UI 자산 용어

이 절은 화면을 만드는 사람이 사용하는 용어다. 사용자에게 표시할 명칭과 구분한다.
근거는 [v2 자산 목록](work/s5-design-system-v2/evidence/inventory.json)과 [명칭 검수](work/s5-terminology/review.md)다.

| 용어 | 의미와 식별자 |
|---|---|
| 타입 배지 | 포켓몬 타입 이름을 색상 배경 위에 표시하는 UI 원자다. v2 자산은 `Type Badge` `118:134`다. |
| 타입 태그 | 주 타입과 보조 타입의 배지 목록이다. `Traits` 안의 두 `Type Badge` 인스턴스로 구성한다. 보조 타입이 없으면 숨긴다. |
| 타입·성격 조합 | 내부 자산 `Traits` `119:969`의 설명이다. 원작의 특성 기능을 뜻하지 않는다. |

## 제외 항목과 저장 보존

별명과 모습 선택 기능은 새 화면에서 제공하지 않는다. 이름은 종 이름을 표시한다.
[스펙 미확정] 이식 정책을 정할 때까지 기존 저장의 `nick` · `look` 필드와 구매 권리를 보존한다.
진화 전 종의 등록 유지와 재소환은 기존 S5 설계의 기록이다. 상품 명칭의 채택 근거로 사용하지 않는다.
박스 화면과 보관 개념은 제거한다.

## 미확정 용어와 채택 근거 정정

아래 이름은 확정 명칭 목록에 넣지 않는다. 원작에 있는 용어인지보다 이 제품에서 사용자가 채택한 기능인지 먼저 확인한다.

| 기존 명칭 | 확인한 출처 | 현재 취급 |
|---|---|---|
| 디버프 | 이전 문서의 상태 표시 용어 | [스펙 미확정] 명칭과 효과의 채택 근거가 필요하다. 숨김 상태나 피로·친밀도 감소를 뜻하는 확정 용어로 쓰지 않는다. |
| 이로치 | 이전 문서의 색상 차이 명칭 | [스펙 미확정] 명칭 채택과 색상 변경 기능의 채택을 구분한다. 특정 상품의 존재나 효과를 뜻하지 않는다. |
| 민트 | 기존 S4 상품 `mint`와 S5 문서 | [스펙 미확정] 기능 필요 여부와 사용자 채택 근거를 확인한다. |
| 진화의돌 | 기존 S5 문서 | [스펙 미확정] 기능·상품 추가 자체가 확인 대상이다. 가격만 미정인 확정 상품으로 취급하지 않는다. |
| 랜덤알 | 기존 S5 문서 | [스펙 미확정] 무작위 획득과 작업 부화 자체가 확인 대상이다. |
| 이로치 도구 | 기존 S5 문서. S4에는 `shiny` 구매가 있다. | [스펙 미확정] 색상 기능과 구매·도구 사용 방식은 별도 결정이다. |

출처와 정정 범위는 [명칭 검수](work/s5-terminology/review.md)를 따른다. 과거 문서의 사용자 결정 표기만으로 채택 사실을 인정하지 않는다.
