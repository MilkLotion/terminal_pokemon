# 화면 명칭 사전

갱신: 2026-09-21. 적용 범위: S5 이후 사용자 화면. 기존 코드 식별자는 별도 이식한다. Figma 자산 매핑은 현재 v2를 따른다. 과거 매핑은 보관 자료에 있다.

| 명칭 | 의미와 사용 규칙 |
|---|---|
| 포켓몬 | 도감에 등록한 뒤 소환하는 종이다. 종별 육성 기록과 재소환 방식은 설계 문서에서 정한다. |
| 파티 | 함께할 포켓몬을 지정하는 칸이다. 최대 여섯 칸이다. |
| 도감 등록 | 해당 종을 소환할 수 있는 상태다. 도감 전체 목록에 보이는 것과 구분한다. |
| 소환 | 도감에 등록된 종을 파티 칸에 배치하는 것이다. |
| 교체 | 파티 칸의 포켓몬을 도감에 등록된 다른 종으로 바꾸는 것이다. 이전 종의 등록과 육성 기록은 그대로 유지한다. |
| 소환 해제 | 파티 칸을 비우는 것이다. 도감 등록과 육성 기록은 보존한다. |
| 표시 / 숨기기 | 숨긴 포켓몬은 이미지 영역 우측 위의 작은 닫힌 몬스터볼로 표시한다. 이 상태는 파티 배치를 바꾸지 않는다. 상태 조작에는 툴팁과 접근성 이름을 제공한다. |
| 디버프 | [스펙 미확정] 이전 문서가 상태 표시를 설명하며 사용한 용어다. 사용자 화면 명칭과 피로·친밀도 감소 효과를 확정한 근거로 사용하지 않는다. 숨김 상태와 구분한다. |
| 타입 배지 | 포켓몬 타입 이름을 색상 배경 위에 표시하는 UI 원자다. v2 자산은 `Type Badge` `118:134`다. |
| 타입 태그 | 주 타입과 보조 타입의 타입 배지 목록이다. v2에서는 `Traits` 안의 두 Type Badge 인스턴스로 구성한다. 보조 타입이 없으면 숨긴다. |
| 타입·성격 조합 | 내부 Figma 자산 `Traits` `119:969`의 설명이다. 사용자에게 표시할 명칭은 아니다. 원작의 특성 기능을 뜻하지 않는다. |
| 가방 | 구매한 도구와 알을 보관하고 사용하는 화면이다. |
| 도구 | 가방에 보관하는 상품 분류다. 사용할 때 대상 포켓몬을 선택한다. |
| 이로치 | [스펙 미확정] 기존 문서의 색상 차이 명칭 후보다. 사용자 채택 근거를 다시 확인한다. 특정 상품의 존재나 효과를 뜻하지 않는다. |

| 포켓몬 표시 | 기존 '무대 표시' 명칭을 대체한다. 화면 문구에 '무대'라는 말을 쓰지 않는다. |
| 클릭 통과 | [스펙 미확정] 기존 '고스트 모드' 명칭을 대체하는 제안이다. 켜면 포켓몬 뒤의 창을 클릭할 수 있다. |
| 데스크톱에서 사용 | [스펙 미확정] 기존 '동반자 모드' 명칭을 대체하는 제안이다. 내부 식별자 `companion`은 그대로 유지한다. |
| VS Code에서 사용 | [스펙 미확정] 기존 '창 모드' 명칭을 대체하는 제안이다. 내부 식별자 `window`는 그대로 유지한다. |
| 터미널 세션에서 사용 | [스펙 미확정] 기존 '세션 모드' 명칭을 대체하는 제안이다. 내부 식별자 `session`은 그대로 유지한다. |

별명과 모습 선택 기능은 새 화면에서 제공하지 않는다. 이름은 종 이름을 표시한다.
[스펙 미확정] 이식 정책을 정할 때까지 기존 저장의 `nick` · `look` · `everstone` 필드와 구매 권리를 보존한다.
에버스톤은 사용자가 구상하지 않았다고 정정한 항목이다. S5 채택 명칭이나 요구 기능으로 취급하지 않는다. 기존 코드에 존재한다는 사실과 구분한다.
진화 전 종의 등록 유지와 재소환은 기존 S5 설계의 기록이다. 상품 명칭의 채택 근거로 사용하지 않는다.
박스 화면과 보관 개념은 제거한다.
실행 명령 `pokebuddy companion`은 이번 화면 명칭 변경으로 바꾸지 않는다.

## 2026-09-21 — 채택 근거 정정

아래 이름은 확정 명칭 목록에 넣지 않는다. 원작에 있는 용어인지보다 이 제품에서 사용자가 채택한 기능인지 먼저 확인한다.

| 기존 명칭 | 확인한 출처 | 현재 취급 |
|---|---|---|
| 에버스톤 | 기존 코드 `everstone`과 한국어 문구 | 사용자가 구상한 적 없다고 정정했다. S5 요구사항에서 제외한다. 대체 명칭을 임의로 만들지 않는다. |
| 민트 | 기존 S4 상품 `mint`와 S5 문서 | [스펙 미확정] 기능 필요 여부와 사용자 채택 근거를 확인한다. |
| 진화의돌 | 기존 S5 문서 | [스펙 미확정] 기능·상품 추가 자체가 확인 대상이다. 가격만 미정인 확정 상품으로 취급하지 않는다. |
| 랜덤알 | 기존 S5 문서 | [스펙 미확정] 무작위 획득과 작업 부화 자체가 확인 대상이다. |
| 이로치 도구 | 기존 S5 문서. S4에는 `shiny` 구매가 있다. | [스펙 미확정] 색상 기능과 구매·도구 사용 방식은 별도 결정이다. |

출처와 정정 범위는 [명칭 검수](work/s5-terminology/review.md)를 따른다. 과거 문서의 사용자 결정 표기만으로 채택 사실을 인정하지 않는다.
