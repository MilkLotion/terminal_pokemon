# 검수 역할

수용 조건에 맞춰 변경 범위를 확인한다.

- 문서 변경에는 `node scripts/check-docs.cjs`를 실행한다.
- 변경한 문장에 [의미 검수](../writing.md#완료-전-의미-검수)를 적용한다.
- 코드 변경에는 관련 검사를 선택한다. 빌드·린트는 사용자 요청 시 실행한다.
- 화면이나 플랫폼 동작이 바뀌면 해당 검사를 추가한다.
- 실제 기능 검사는 임시 HOME과 임시 데이터로 실행한다.
- 실행 명령과 결과를 기존 작업 기록의 검수 절에 적는다.
- 미실행 검사는 미실행으로 적는다.

자동 문서 검사의 통과를 문장 의미나 ASD-STE100 준수의 증거로 사용하지 않는다.
